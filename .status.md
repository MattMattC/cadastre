## Notes

- **Stack** : Vite + React 18 + TypeScript ; Leaflet/MapLibre pour la carte ; Konva pour annotations sur canvas
- **Démarrage** : `npm install && npm run dev` → serveur en http://localhost:5173 (testable sur mobile via URL réseau)
- **Structure** : MapPage (recherche simple) vs EditorPage (éditeur complet avec sélection, toolbar flottante, palette de symboles)
- **Données** : APIs IGN/DGFiP gratuites (Géoplateforme, WMTS cadastre, GeoJSON communes) sous Licence Ouverte 2.0
- **État** : MVP fonctionnel (phase 1-2) + annotations avancées (phase 3 partielle) ; persistance locale et export manquent
- **Récent** : annotations à l'échelle terrain (zoom/rotation), sélection multi-parcelles, éditeur texte inline, légende interactive
